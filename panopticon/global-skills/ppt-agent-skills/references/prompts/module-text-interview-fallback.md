# Text Fallback Mode -- 结构化文本采访单

## 强制执行纪律

1. **极致静默**：直接抛出下方的文本采访单，严禁附加寒暄、前言或“为什么要问”的解释。
2. **严禁退化**：不支持 UI 不等于退化成填空题。必须完整输出带备选项的结构化清单（禁止变成单行密集的 `场景=；受众=...`）。

## 固定输出格式

```markdown
请按如下清单直接回复（填写序号或补全说明，不确定选“默认”）：

**A. 场景与目标**
- 场景：【A. 严肃内部汇报(对齐目标)】 【B. 单页简报/Executive one-pager(给老板一页看完)】 【C. 重量级产品宣讲(抓眼球)】 【D. 招商/融资路演(秀实力)】 【E. 知识型培训课件(重逻辑)】 【F. 其他:___】
- 身份与受众：【A. 一线操盘手向高层汇报(要资源/讲成效)】 【B. 业务一号位向外部客户布道(画大饼/重利益)】 【C. 技术骨干与硬核同行切磋(扣细节)】 【D. 专业人士向泛大众科普(求易懂)】 【E. 其他:___】
- 目标：【A. 扭转认知/刷新观念】 【B. 促成拍板决策或掏钱】 【C. 吸引对方主动加入/传播】 【D. 纯信息铺陈同步】 【E. 其他:___】

**B. 内容与边界**
- 期望页数：【A. 1页简报(结论+KPI+风险+行动闭环)】 【B. 5-10页(微型/短汇报)】 【C. 10-20页(标准)】 【D. 20-30页及以上(宽幅深度盘点)】 【E. 让AI凭内容自动决断】
- 密度：【A. 极简呼吸感(字少图大，Apple-Style)】 【B. 均衡图文(主次分明)】 【C. 高密度但可读(4-6模块，适合简报)】 【D. 极高密度干货(麦肯锡式详实/情报板)】
- 资料：【A. Research(主主代理全网扩写做发散)】 【B. 严格闭卷(不发散，只用现有文字)】
- 核心主张与红线：【自由补充。例如：全篇必须打透的唯一主张是“我们比竞品快三倍”；绝对禁止提xx公司的名字】

**C. 视觉与资产策略**
- 风格：【A. 蓝灰数据向极简商务】 【B. 赛博/暗色流光科技极客】 【C. 活泼多色的动感/流行风】 【D. 让AI凭主题自决定】 【E. 其他:___】
- 语言：【A. 中文】 【B. 英文】 【C. 中英双语/专业术语多用英文】
- 配图策略：【A. 无脑 Decorate(装饰点缀)】 【B. Generate(让AI做插画/文生图)】 【C. Provide(有指定图库)】 【D. 仅留空占位槽】
- 品牌定制：【自由补充，例如：主色设为 #FF0000】

**D. 架构控制**
- 模型：【A. 子代理模型同主代理】 【B. 指定更强/更快的模型:___】
```

## 默认快捷回复

如果用户只想最快推进，可以直接回复：`全部按默认，用 research`。

此时主 agent 在归一化时应至少展开为：

- `material_strategy: research`
- 场景、受众、目标、风格、语言、配图策略全部采用默认推荐值

## 归纳后的问答落点

主 agent 收到用户回复后，必须把文本答案归纳进结构化锚点，至少包含：

- `presentation_scenario`
- `expected_pages`
- `target_action`
- `page_density`
- `visual_style`
- `language_mode`
- `imagery_strategy`
- `material_strategy: research`（当用户使用默认快捷回复，或明确选择 research 时）
